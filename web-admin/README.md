# Rancak.in Web Admin & Simulator Studio (FS-1)

Aplikasi Web Admin berbasis Next.js / TypeScript untuk:
1. **Pilar 8 (Dashboard Dispar)**: Analitik kunjungan real-time, heatmap kepadatan 19 Kab/Kota Sumbar, dan perputaran ekonomi UMKM nagari.
2. **Pusat Komando Satgas Saber Pungli**: Verifikasi dan ubah alur status tiket aduan (`Masuk` → `Diverifikasi` → `Ditindaklanjuti` → `Selesai`).
3. **CMS Studio 360° Visual Editor**: Unggah foto panorama 360°, klik-tempel koordinat 4 Pin interaktif (`pitch` & `yaw`), kurasi lokasi sensitif, serta pengelolaan standar tarif Perda.
4. **Panel Simulator Pengujian**: Layar simulasi interaktif Bot WhatsApp Mitra (balas `1 Terima` / `0 Tolak` & scan QR pencairan Escrow) + Web Instant Smart QR & Group Invite.

## Menjalankan Web Admin
```bash
cd web-admin
npm install
npm run dev
```
