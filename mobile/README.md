# Rancak.in Mobile App (Flutter)

Aplikasi mobile dan PWA untuk **Ekosistem Wisata Pintar Sumatera Barat (Rancak.in)**.

## Tim Pengembang
- **FE-1 (Frontend 1)**: Visual 360°, Peta, Medan, & Offline (`lib/features/fe1_visual_map/`)
- **FE-2 (Frontend 2)**: Planner, Group, Escrow, & Gamifikasi (`lib/features/fe2_planner_escrow/`)

## Standar Desain (`desain.md`)
- **Latar Halaman**: `--cream-100` (`#F6F3EC`)
- **Tombol Utama**: `PillButton` tinggi 52px, warna `--green-800` (`#234B24`)
- **Aksen Kritis**: `--coral-500` (`#F26B4B`)
- **Target Sentuh Minimum**: 44 × 44 px
- **Ukuran Kanvas Standar**: 390 × 844 px

## Menjalankan Aplikasi
```bash
cd mobile
flutter pub get
flutter run
```
